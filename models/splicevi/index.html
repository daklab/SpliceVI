    SpliceVI

    SpliceVI is a multimodal variational autoencoder that jointly models gene expression and alternative splicing (junction usage / PSI) from single-cell data. It learns a joint low-dimensional latent space from both modalities, which is used to impute junction usage and to test for differential splicing and expression.

    SpliceVI follows the same overall architecture and inherits the same scvi-tools mixins as MultiVI (Ashuach et al., 2021), which jointly models RNA-seq and chromatin accessibility. The key difference is that the ATAC branch is replaced throughout by a splicing-specific branch, with a missingness-aware encoder, a splicing-specific decoder, and splicing likelihoods (Binomial / Beta-Binomial / Dirichlet-Multinomial) suited to the PSI scale. The DE/DS analysis API mirrors MultiVI's, with get_normalized_splicing and differential_splicing replacing the accessibility equivalents.

    Ashuach T*, Gabitto MI*, Jordan MI, Yosef N. MultiVI: deep generative model for the integration of multi-modal data. bioRxiv, 2021.

    Model overview

    SpliceVI uses two separate encoder branches, one for gene expression and one for splicing, whose posteriors are mixed into a joint latent space. Two decoder branches reconstruct each modality from the joint latent.

    Gene expression ──► GE Encoder ──► q(z|x_e) ──┐
                                                ├──► Mix ──► z ──► GE Decoder ──► x_e
Splicing (PSI) ───► Splice Encoder ──► q(z|x_s) ─┘              └──► Splice Decoder ──► x_s

    Splicing encoder

    Because splicing observations are highly sparse (many junctions are unobserved in a given cell), SpliceVI uses a missingness-aware partial encoder (PartialEncoderEDDIFaster). The design draws inspiration from the EDDI framework (Ma et al., 2019), which handles pervasive missing values in VAEs using feature embeddings and exchangeable neural networks (see also the SpliceVI preprint). The encoder works in three steps.

    1. Embeds each observed junction independently via a shared \(h\) network. By default (psi_input="deviation") the input is how much the junction's usage in the cell differs from its usage across all cells, so that which junctions are detected carries no signal on its own
    2. Pools the per-junction embeddings across all observed junctions in a cell (divided by a fixed number, the median number of observed junctions per training cell)
    3. Maps the pooled representation through an MLP to produce posterior statistics \((\mu, \sigma^2)\)

    Unobserved junctions are left out of the input rather than set to zero, so no values are imputed at the input.

    Splicing likelihood

    Three options are supported.

    Option Description
    binomial Simple binomial over junction read counts
    beta_binomial Beta-binomial with a learned per-junction concentration \(\phi_j\)
    dirichlet_multinomial Dirichlet-multinomial over the junctions of each ATSE, with a learned concentration per ATSE, so junction probabilities within an ATSE sum to 1

    The default, used for the paper's models, is dirichlet_multinomial.

    Modality mixing

    The two per-modality posteriors are combined into a single joint posterior before sampling. The mixing strategy is controlled by the modality_weights argument. equal, universal and cell are the options of MultiVI.

    Option Description
    equal Fixed 50/50 average (default)
    universal One global learned weight per modality
    cell Per-cell learned weights
    per_dimension_weighted_average One learned splicing weight per latent dimension, with mean weight 0.5
    concatenate Concatenate both latents (no mixing, doubled latent size)

    Architecture

    Component Default Options
    Splicing encoder partial vanilla, partial
    Splicing decoder vanilla vanilla, linear
    Expression decoder vanilla vanilla, linear
    Splicing likelihood dirichlet_multinomial binomial, beta_binomial, dirichlet_multinomial
    Latent distribution normal normal, ln

    API reference

    splicevi.SPLICEVI

    Bases: VAEMixin, UnsupervisedTrainingMixin, BaseModelClass, ArchesMixin

    Joint model of gene expression and alternative splicing (junction usage) in single cells.

    SPLICEVI learns one latent space from both modalities: an expression encoder and a splicing encoder each give a posterior over the latent space, the two are mixed into a joint posterior, and one decoder per modality reconstructs the data (zero-inflated negative binomial for expression, Dirichlet-multinomial over the junctions of each ATSE for splicing). It wraps the :class:~splicevi.splicevae.SPLICEVAE module.

    The defaults are the settings of the paper's models, so SPLICEVI(mdata) followed by model.train() trains the paper's model. :meth:preset returns the same settings as dictionaries, with the variants for a batch key (atlas="tms") and for a reference plus a sparse atlas ("sparse", joint=True).

    finetune_decoders(query_mdata, reference_mdata, n_query_per_step=32, n_reference_per_step=128, lr=0.0001, max_epochs=300, early_stopping_patience=30, validation_fraction=0.1, seed=20261137, set_torch_seed=True, max_minutes=None, checkpoint_dir=None, fix_depth_inputs=True, query_covariate_value=1.0, reference_covariate_value=0.0)

    Adapt a trained model to a new atlas by fine-tuning only its decoders, plus one technology input.

    Use when this model was trained on a reference atlas (e.g. Allen Brain, deep Smart-seq) and you want its expression and splicing estimates for a new, sparser atlas of the same tissue (e.g. EasySci, single-nucleus 3') without retraining from scratch. The encoders are not changed, so query cells are placed in the reference latent space; the decoders learn the query data's expression and splicing levels. Defaults are the same as what's used in the paper's EasySci model.

    What happens:

    1. One zero-initialized decoder covariate input is added to the first hidden layer of both decoders (technology: reference_covariate_value for reference cells, query_covariate_value for query cells). At zero weights the model is the reference model.
    2. Everything is frozen except the two decoders and the covariate weights. Kept from the reference model: the encoders, junction embeddings and latent mixing, the deviation input's population PSI and pool divisor, the per-ATSE splicing concentrations and the gene dispersions (re-learning the last two on the query data predicted held-out query reads worse in the paper's tests, so it is not offered).
    3. With fix_depth_inputs (models with decoder_depth_covariates), the decoders' depth inputs are fixed at the reference training mean for every cell, since the reference depth statistics do not describe the query data. The cross-modality gate is set open, as at the end of training.
    4. Each step uses n_query_per_step query cells and n_reference_per_step reference cells (the reference "replay" keeps the decoders fitting the reference); loss = query loss + reference loss; Adam at lr.
    5. A random validation_fraction of the query cells is held out for early stopping (patience early_stopping_patience epochs, at most max_epochs, optional wall-clock limit max_minutes).
    6. The best state is restored and the model is left decoding as query data (decoder covariate = query_covariate_value), ready for :meth:differential_splicing etc. on the query cells.

    Calling it again continues from the current weights with a fresh optimizer. Training a fine-tuned model with :meth:train is not supported: every cell would get decoder_covariate_value, so the covariate weights would act as a plain bias.

    get_normalized_expression_ZINB(adata=None, indices=None, n_samples_overall=None, transform_batch=None, gene_list=None, use_z_mean=True, n_samples=1, batch_size=None, return_mean=True, return_numpy=False, silent=True, sample=False, return_counts=False)

    Returns ZINB posterior-mean normalized expression (the expression analogue of :meth:get_normalized_splicing_DM). Only valid for gene_likelihood="zinb".

    The ZINB is a Gamma-Poisson mixed with a point mass at zero. With decoder mean :math:\mu (px_rate), inverse dispersion :math:\theta (px_r) and dropout probability :math:\pi = \sigma(\text{px\_dropout}), the posterior mean of the underlying rate given the observed count :math:y is

    • :math:y > 0: :math:E[\lambda \mid y] = \mu (\theta + y) / (\theta + \mu), i.e. a weighted average :math:\tfrac{\theta}{\theta+\mu}\mu + \tfrac{\mu}{\theta+\mu} y of the decoder and the data;
    • :math:y = 0: with :math:w = P(\text{dropout} \mid y=0) = \pi / (\pi + (1-\pi)(\theta/(\theta+\mu))^\theta), :math:E[\lambda \mid 0] = w \mu + (1-w)\, \theta\mu / (\theta+\mu) (a dropout zero carries no information; a sampling zero pulls the estimate down).

    The result is divided by the cell's library factor (px_rate / px_scale), so it is on the same scale as :meth:get_normalized_expression (px_scale) and can replace it in DE. Parameters and return shape are the same as :meth:get_normalized_expression, plus:

    sample If True, return one random draw from the posterior instead of its mean: for y > 0, :math:\lambda \sim \mathrm{Gamma}(\theta + y,\ \theta/\mu + 1); for y = 0, with probability w the prior :math:\mathrm{Gamma}(\theta, \theta/\mu) (dropout zero) and otherwise :math:\mathrm{Gamma}(\theta, \theta/\mu + 1) (Gamma shape / rate). Used by DE with norm_expression_function="zinb_posterior_sample", so each Monte Carlo draw carries the uncertainty of each cell's expression given its counts. return_counts If True, do not divide by the library factor (values on the count scale, e.g. for pseudobulk sums).

    init_decoder_intercept_from_adata()

    Start the splicing decoder's per-junction bias at log(population PSI), clipped to [1e-4, 1].

    With the hidden contribution at zero, the decoder then reproduces the population PSI: generative() maps sigmoid(bias) -> clamp -> logit -> softmax within the ATSE, which is the softmax of the bias over the ATSE.

    init_depth_covariate_stats_from_adata()

    Mean and standard deviation over the training cells of [log1p detected genes, log1p observed junctions, log1p library size], stored as buffers so the decoders' depth covariates are standardized with training constants (same definitions as in SPLICEVAE.inference).

    init_feature_embedding_from_adata()

    Start the partial encoder's junction embeddings from a truncated SVD of the junction-usage matrix.

    init_junc2atse()

    Build the junction-to-ATSE matrix from var["event_id"] of the splicing modality (once).

    init_pool_divisor_from_adata()

    Set the partial encoder's fixed pooling divisor (psi_input="deviation"): the median number of observed junctions per training cell.

    init_pop_psi_from_adata()

    Fill the partial encoder's pop_psi buffer with the population PSI of the training data (psi_input="deviation").

    init_psi_prior_from_adata()

    Population PSI for the pseudo-count prior (psi_prior_pseudocount > 0): read-weighted population PSI per junction; junctions of ATSEs with no reads in the training data get 1 / (junctions in the ATSE), so the prior is a distribution within every ATSE.

    Sparse (junctions x ATSEs) matrix with a 1 where a junction belongs to an ATSE.

    Read-weighted population PSI per junction from the registered count layers of the training data.

    Sum over cells of the junction counts divided by the sum over cells of the ATSE totals (the ATSE count layer repeats the ATSE total on every junction of the ATSE, so its column sum is the ATSE's read total); 0 for junctions without reads.
