    SPLICEVAE

    The underlying PyTorch module. Most users will interact with SPLICEVI rather than this class directly.

    splicevi.splicevae.SPLICEVAE

    Bases: BaseModuleClass

    Variational auto encoder for joint (paired or unpaired) RNA-seq gene expression and alternative splicing (junction usage). Two encoder–decoder branches (expression and splicing) produce posterior latents that are mixed into a shared latent space z.

    Reconstruction is performed per modality. Optional penalties align the two posteriors.

    The defaults are the settings of the paper's models (the same as :class:SPLICEVI's defaults). The model class always passes every setting explicitly, so these defaults only matter when the module is built directly.

    splicing_loss_type (binomial, beta_binomial, dirichlet_multinomial)

    Reconstruction loss for splicing. "binomial" expects junction counts and ATSE totals. "beta_binomial" uses a beta binomial with a learned concentration. "dirichlet_multinomial" uses grouped softmax within ATSEs.

    		 "binomial","beta_binomial","dirichlet_multinomial"
    dm_concentration (atse, scalar)

    For Dirichlet multinomial. Controls whether the concentration is per ATSE or scalar.

    		 "atse","scalar"
    splicing_loss_weight float

    Scalar multiplier applied to the splicing reconstruction loss before it is combined with the expression reconstruction loss. Values > 1 upweight splicing relative to expression; values < 1 downweight it.

    		 1.0
    lambda_prior float

    Weight of the L2 penalty (torch.square(log_phi_j).sum()) pulling the learned per-ATSE (or scalar) log-concentration toward 0, added to the loss whenever splicing_loss_type is "beta_binomial" or "dirichlet_multinomial". This shrinks log_phi_j away from wherever it's initialized (not toward the init value) -- ATSEs with weak/sparse reconstruction-loss gradient collapse toward this prior's fixed point (log_phi_j=0, i.e. phi=softplus(0)~=0.69) while ATSEs with strong data support resist it. Higher values shrink more aggressively; 0.0 disables it. Only used when phi_prior="l2_log".

    		 1e-2
    phi_floor float

    Minimum concentration: phi = phi_floor + softplus(log_phi_j). Additive so the gradient stays smooth (a clamp would kill it below the floor). 0.0 = no floor.

    		 0.0
    phi_prior (l2_log, gamma, none)

    Regularizer on the concentration. "l2_log" is an L2 pull of log_phi_j toward 0 (weight lambda_prior, divided by batch size). "gamma" is a MAP Gamma(phi_prior_shape, phi_prior_rate) prior on the effective phi, scaled by 1/n_obs (proper MAP scaling for a per-cell-mean loss). "none" disables it.

    		 "l2_log","gamma","none"
    psi_prior_pseudocount float

    Pseudo-count prior on the decoded PSI (dirichlet_multinomial only): adds -psi_prior_pseudocount * sum_j pi_j log p_j per cell, i.e. that many virtual reads per ATSE distributed as the population PSI pi (buffer psi_prior_pop, filled by the model class). Entries without reads are pulled to the population PSI; entries with reads are dominated by their data. 0 = off.

    		 0.0
    phi_prior_shape float, defaults 2.0, 0.1

    Gamma prior parameters (rate parametrization; defaults give mean 20, sd ~14).

    		 2.0
    phi_prior_rate float, defaults 2.0, 0.1

    Gamma prior parameters (rate parametrization; defaults give mean 20, sd ~14).

    		 2.0
    phi_init (constant, log100, prior)

    "constant" starts every raw log_phi_j at exactly log 100 (phi ~ 4.6 after softplus). "log100" adds a random draw to that start (raw log_phi_j ~ N(log 100, 0.5)); the per-ATSE concentration is not identified from the data, so the draw only adds variance between replicates. "prior" samples phi from the Gamma prior (clamped above the floor) and inverts softplus.

    		 "constant","log100","prior"
    code_dim int

    Dimensionality of per junction codes before pooling.

    		 64
    h_hidden_dim int

    Hidden width of the per junction h subnetwork that combines PSI and feature embedding.

    		 128
    encoder_hidden_dim int

    Hidden width of the post pooling MLP that maps the pooled code to (mu, log var) of z.

    		 128
    pool_mode (mean, sum)

    Aggregation of per junction codes within each cell.

    		 "mean","sum"
    psi_input (deviation, raw)

    Input of the partial splicing encoder. "deviation": each observed junction's PSI minus its read-weighted population PSI (buffer pop_psi, filled by the model class), the per-junction network's output at zero deviation is subtracted, and the pool is divided by a fixed number (the median number of observed junctions per training cell, buffer pool_divisor), so the pooled code does not carry the number of observed junctions. Needs pool_mode="mean". "raw": the observed PSI itself, averaged over the observed junctions.

    		 "deviation","raw"
    decoder_depth_covariates bool

    Give both decoders (never the encoders) three standardized depth inputs per cell: log1p detected genes, log1p observed junctions and log1p library size (standardized with the training data's mean and standard deviation, buffers depth_cov_mean / depth_cov_std). Vanilla splicing decoder only.

    		 True
    max_nobs int

    Optional cap on the number of observed entries processed in each scatter chunk. A negative value disables chunking.

    		 -1
    n_decoder_covariates int

    Number of decoder covariate inputs (e.g. 1 for technology: 0 = reference data, 1 = query data). Each adds zero-initialized weights to the first hidden layer of both decoders (decoder_covariate_weight_expression and decoder_covariate_weight_splicing, one column per covariate), so at zero weights the model is unchanged. The value used for every cell is the buffer decoder_covariate_value unless decoder_covariate_batch (one row per cell) is set, as during :meth:SPLICEVI.finetune_decoders. Added after training by :meth:add_decoder_covariates; 0 = no covariate inputs. Vanilla decoders only.

    		 0
    modality_weights (equal, cell, universal, concatenate, per_dimension_weighted_average)

    How to combine expression and splicing posteriors. "per_dimension_weighted_average" learns a per-latent-dimension splicing contribution weight w_d in [0,1] (expression weight = 1-w_d), constrained so the mean weight stays at 0.5 (preventing one modality from dominating globally).

    		 "equal","cell","universal","concatenate","per_dimension_weighted_average"
    modality_penalty (Jeffreys, MMD, None)

    Alignment penalty between the two posteriors on paired cells.

    		 "Jeffreys","MMD","None"
    mask_cells_without_splicing bool

    If True, a cell with no observed junction (psi_observed_mask all 0) is treated as lacking the splicing modality: it gets no splicing weight in the latent mix and is excluded from the modality-alignment penalty. If False (default) every cell always counts as having splicing, so a cell with no splicing reads still has its (uninformed) splicing posterior averaged into the joint latent.

    		 False
    variance_mixing (sqrt_weights, linear, squared)

    How the two encoders' variances are combined into the joint posterior variance for modality_weights in {"equal","cell","universal","per_dimension_weighted_average"} (ignored for "concatenate"). The mean is always the weighted average of means. "sqrt_weights": for equal/cell/universal the MultiVI heuristic sum(sqrt(w) * v) (~1.41x the average variance under equal weights); for per_dimension_weighted_average the rule (sum(w * std))2, the variance of an average of perfectly correlated errors. "linear" uses sum(w * v) (no inflation). "squared" uses sum(w2 * v), the variance of a weighted average of independent Gaussians (per-dimension w in the per-dimension mode); the default.

    		 "sqrt_weights","linear","squared"

    Notes

    The partial splicing branch uses a single PartialEncoderEDDIFaster encoder that aggregates only observed junctions per cell. The same n_layers_encoder parameter controls the depth of the final MLP that produces latent statistics for this branch.

    add_decoder_covariates(n_covariates=1)

    Add n_covariates zero-initialized covariate inputs to the first hidden layer of both decoders.

    Same as appending the covariates to each decoder's input: the first layer's output gets covariates @ W.T with W = decoder_covariate_weight_<decoder> (hidden units x covariates), initialized at zero so the model's output is unchanged until W is trained. The value fed for every cell is decoder_covariate_value (buffer, saved with the model; zeros = reference data) unless decoder_covariate_batch holds one row per cell.

    decoder_first_layers()

    The first Linear layer of each decoder, which the decoder covariate inputs feed: {"expression": ..., "splicing": ...}.

    dirichlet_multinomial_likelihood(counts, atse_counts, junc2atse, alpha, mask=None)

    Computes each cell’s Dirichlet–multinomial log-likelihood, masking out any junctions where mask==0 and any ATSE-groups where atse_counts==0.

    Returns: Tensor of shape (N,) giving per-cell log-likelihood: ll[i] = sum_over_groups LL_group(i,g) – sum_over_junctions LL_junc(i,p)

    inference(x, mask, batch_index, cont_covs, cat_covs, label, cell_idx, size_factor, n_samples=1)

    Run the inference network.

    Splits input x into gene expression and splicing parts, encodes each branch, and mixes their latent representations.

    init_log_phi(size)

    Initial raw concentration parameter. size=None gives the scalar DM parameter.

    "constant" (default): every value starts at log 100 (phi = softplus(log 100), about 4.6). "log100": the same start plus a random draw (per-ATSE / per-junction: N(log 100, 0.5); scalar: 4.6). "prior" samples phi from the Gamma prior, clamps it above the floor, and inverts softplus so get_phi() starts at that sample.

    loss(tensors, inference_outputs, generative_outputs, kl_weight=1.0)

    Compute the total loss combining gene expression and splicing reconstruction losses, latent KL divergence, and the modality alignment penalty.

    For splicing, if count data is provided (via the keys "atse_counts_key" and "junc_counts_key"), the loss is computed using the specified binomial, DM, or beta-binomial likelihood; otherwise, binary cross-entropy is used.

    Returns:

    Type Description
    LossOutput

    A container with total loss, reconstruction losses, and KL divergence details.

    phi_prior_loss(batch_size)

    Regularizer on the concentration (0.0 for non-DM/BB likelihoods or phi_prior='none').
